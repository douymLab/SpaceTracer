# Step 6: Phylogeny (optional)

SpaceTracer phylogeny reconstruction currently depends on the external PhyloSOLID repository:

- [PhyloSOLID](https://github.com/douymLab/PhyloSOLID)

Use mutation outputs (for example Step 5 final calls) as input for downstream tree-building workflows in PhyloSOLID.

In future releases, this dependency may be integrated directly into SpaceTracer.
